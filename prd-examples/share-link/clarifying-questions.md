# Clarifying questions: Report share links

The input covered all the essentials but left some big decisions open (who can access what), so
prd-creator asked these questions before writing. The example PRD in this folder shows the
"just write it" path: these decisions appear under "Please confirm" in its Assumptions section.

1. **Does a link grant access by itself?** Or does it only work for people who already have access to the report (with everyone else seeing "Request access")? Your criteria suggest the second, but this decides the whole permission model.
2. **Who can create and disable links?** Owners only, or editors too? Can viewers copy an existing link?
3. **Access requests:** when someone clicks "Request access," how is the owner notified (email, in-app, both), and is approving requests part of this feature or handled by existing access management?
